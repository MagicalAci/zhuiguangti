# 追光体 — 用户痛点与产品功能规划

> 基于 05-12 内部会议纪要 + 四位团长深度访谈报告
>
> 输出时间：2026-05-12

---

## 一、目标用户画像

### 1.1 团长（KOL/KOC）— 核心供给侧

| 类型 | 代购型团长 | 自制周边型团长 |
|---|---|---|
| 代表 | 团长A（偶像梦幻祭）、团长B（盲盒类） | 团长C（蜡烛香薰）、团长D（实用谷+观赏谷） |
| 盈利模式 | 无盈利/微利，为爱发电 | 有盈利，利润率 20-30%，单团纯利 1.5w-8w |
| 团规模 | 100-500人/团 | 200-20000人，每次跟团 2000-3000人 |
| 团队 | 2-5人兼职合伙 | 1人+1-4个管理员（免单换劳动） |
| 开团频率 | 一年3-4团（效率瓶颈） | 一年约7团（流程相对成熟） |
| 核心流程 | 官方信息→群评论排序→手动Excel→收全款→代购→拆分→发货 | 设计/约稿→意向金→打样→定金→补货→尾款→制作→代发 |
| 工具现状 | QQ群相册 + Excel + 群拼股助手 | 拼团呀 / 开团吧 + 小红书 + QQ/微信群 |

### 1.2 团员（买家）— 核心需求侧

- **人群画像**：以年轻女性为主（高中生、大学生至28岁），对IP有高热情
- **覆盖圈层**：二次元、追星、Coser、画师粉丝、地下偶像粉丝等兴趣圈层
- **分布场所**：散落在闲鱼、B站、千岛、微信群、QQ群各处，无统一社区

## 二、用户痛点深度清单

### 2.1 团长侧痛点（按严重程度排序）

#### P0 — 致命痛点（直接导致效率崩溃或资金风险）

| # | 痛点 | 详细描述 | 影响人群 |
|---|---|---|---|
| 1 | **手工排表极度低效** | 团长依赖QQ群相册评论+手动Excel排单，54个角色的排表需要手动逐行匹配，一次开团仅排表就耗费数天。漏单、错单、行错位频发 | 代购型（A、B） |
| 2 | **收款与订单系统完全割裂** | 小程序只能展示商品，收款靠个人微信/支付宝二维码扫码转账，团长需要人工审核每笔转账凭证。2000-3000人的团需要4个管理员轮班审核 | 全部团长 |
| 3 | **定金-尾款多段收费管理混乱** | 自制型团长有"意向金→定金→尾款"三段收费，代购型有"定金→尾款"两段收费。每段都需要手动对账，重复支付、漏交、错付频发，追溯极困难 | 全部团长 |
| 4 | **催款无手段、逃单无追责** | 催款只能在群里喊话或私聊，无系统化催付能力。逃单后货物压在代发公司，资金被套。团长无法有效约束团员 | 全部团长（D最严重） |
| 5 | **冷热捆绑规则极度复杂** | 54个角色分冷热池，热门角色需搭配1-5个冷门角色，不同热度等级对应不同搭配比例和价格，全靠人脑计算。规则一旦失衡整团失败 | 代购型（A、B） |

#### P1 — 高频痛点（严重影响运营效率）

| # | 痛点 | 详细描述 | 影响人群 |
|---|---|---|---|
| 6 | **跨渠道对账噩梦** | 团员有人用微信，有人用支付宝，团长需要在多个平台的流水中逐笔核对，无法自动匹配订单与收款 | 全部团长 |
| 7 | **补邮费计算与催收困难** | 商品超重需补邮费，但重量因品类差异大，需手动称重+手动计算+手动发补邮链接+手动催收，链路极长 | B、D |
| 8 | **黑名单无法跨团/跨群共享** | 每个团长维护自己的黑名单，跑单用户换个群继续跟团。团长之间无信息互通机制 | 全部团长（强烈需求） |
| 9 | **数据完全不透明** | 使用拼团呀的团长只能看到"订单总额"，看不到"实际已收款金额"。定金和尾款分开收的场景下，团长不知道自己实际收了多少钱 | D（拼团呀用户） |
| 10 | **发货管理混乱（多批次/合并/分批）** | 代购型团长需要多批次海外货物合并发货（1月+2月周边合并），自制型需要分批发货。现有工具不支持"一单多包裹"和"分批发货" | A、B、D |
| 11 | **通知触达能力弱** | 关键进度（打样完成、到货、催付）只能在群里喊，消息被淹没。团员反复在群里问"到哪一步了"，占用大量客服精力 | 全部团长 |

#### P2 — 改善型痛点（提升体验和信任）

| # | 痛点 | 详细描述 | 影响人群 |
|---|---|---|---|
| 12 | **转单流程混乱** | 代购型团长的团员之间经常转单（A不要了转给B），但系统无法变更订单归属和地址，只能群里私下沟通后通知团长手动改 | A |
| 13 | **动态调价无系统支持** | 自制周边在购买人数达到一定阈值后会全员降价（摊薄设计成本），但现有工具不支持"阶梯定价"或"全员调价"，需手动通知 | C、D |
| 14 | **商品上架/补货不够灵活** | 自制型团长需要每周补货、动态上架新SKU、删除滞销SKU。团员需要在已有订单中追加新商品，现有工具支持有限 | D |
| 15 | **团长信用无法证明** | 新团员判断团长是否靠谱只能看主页历史，没有系统化的信用评分、发货率、跑单率等数据展示 | 全部团长 |
| 16 | **汇率计算与国际物流成本分摊** | 海外代购涉及实时汇率差、国际运费分摊、关税分摊，全靠手动计算 | A、B |
| 17 | **工厂/供应链对接门槛高** | 自制周边团长找工厂全靠自己摸索，打样费高（几千元），品控无保障，被"坑"风险大 | C、D |
| 18 | **平台日交易限额** | 拼团呀等平台存在单日交易额/单量限制，大团长需要频繁联系客服提额 | D |

### 2.2 团员侧痛点

| # | 痛点 | 详细描述 |
|---|---|---|
| 1 | **进度完全黑盒** | 付完定金后，商品处于"设计中/打样中/制作中/运输中"的哪一步完全不知道，只能在群里问 |
| 2 | **团长可信度无法判断** | 担心团长跑路（访谈中团员第二关注点），只能靠社交圈口碑判断 |
| 3 | **购买体验割裂** | 在小程序看商品→跳到微信扫码付款→回群上传凭证→等待人工审核，链路长且不流畅 |
| 4 | **规则理解门槛高** | 冷热捆绑、妈位、定金-尾款规则等圈子黑话和复杂规则，新人容易犯错被拉黑 |
| 5 | **重复付款/错付无提醒** | 定金付了两次、尾款算错金额等情况时有发生，团长人工核对效率低 |
| 6 | **没有统一社区** | 想找特定IP的团需要在闲鱼、B站、QQ群、千岛等多个平台搜索，效率极低 |

## 三、产品功能规划

### 3.1 产品定位

**一句话定位**：兴趣圈层的团长经营工具 → 兴趣社区电商

**演进路径**：团长工具（V1）→ 带社区属性的团长工具（V2）→ 兴趣社区电商（V3）

**技术载体**：APP（主体，承载社区+团长管理）+ 小程序（承接分享落地页+快捷下单）

### 3.2 V1 — 团长工具 MVP（解决最痛的效率问题）

#### 模块一：智能开团

| 功能 | 描述 | 解决痛点 |
|---|---|---|
| **开团模板** | 支持"代购团"和"自制团"两套模板，预设不同流程节点 | 规则复杂、流程不清晰 |
| **批量建品** | 支持Excel/文本粘贴批量导入角色/SKU，一键生成商品列表 | 手动逐条上架低效（#1） |
| **冷热分池+捆绑规则引擎** | 团长将SKU标记冷/热，设置捆绑比例（如1热配3冷），系统自动校验下单合规性 | 冷热捆绑规则复杂（#5） |
| **妈位/优先权系统** | 支持设置"妈位"优先购买权，系统自动排序 | 人工排序易出错 |
| **阶梯定价/动态调价** | 支持按购买人数阶梯降价，团长可一键全员调价并自动通知 | 动态调价无系统支持（#13） |
| **灵活补货与SKU管理** | 支持团期内动态上架/下架/补货SKU，团员可在已有订单中追加商品 | 补货不灵活（#14） |

#### 模块二：收款与对账

| 功能 | 描述 | 解决痛点 |
|---|---|---|
| **平台集中收款** | 接入微信支付/支付宝，团员在小程序/APP内直接支付，资金进入平台账户，团长可提现（零手续费） | 收款与订单割裂（#2） |
| **分段收费支持** | 原生支持"意向金→定金→尾款"三段模式，每段独立记账，系统自动计算"应收-已收-待收" | 多段收费管理混乱（#3） |
| **智能对账看板** | 实时展示：订单总额、已收总额、待收总额、各阶段收款明细。自动匹配订单与支付记录 | 数据不透明（#9）、跨渠道对账（#6） |
| **自动催付** | 到期未付自动推送提醒（APP推送+小程序服务通知），支持团长一键群发催付 | 催款无手段（#4） |

#### 模块三：订单与排单管理

| 功能 | 描述 | 解决痛点 |
|---|---|---|
| **自动排表** | 根据下单时间、妈位优先级、冷热捆绑规则自动生成排表，支持一键导出Excel | 手工排表低效（#1） |
| **订单状态机** | 订单支持：待付定金→已付定金→待付尾款→已付尾款→待发货→已发货→已完成，每个状态可触发自动动作 | 流程管理混乱 |
| **转单功能** | A团员可发起转单给B团员，系统自动变更订单归属、收货地址，团长确认即生效 | 转单流程混乱（#12） |
| **逃单处理** | 超时未付自动标记"疑似逃单"，团长可一键取消并释放库存 | 逃单无追责（#4） |

#### 模块四：发货与物流

| 功能 | 描述 | 解决痛点 |
|---|---|---|
| **分批/合并发货** | 支持一单多包裹、多批次合并发货、分批发货。团长可标记"第N批到货"并触发对应发货 | 发货管理混乱（#10） |
| **智能补邮计算** | 根据商品预设重量、购买数量、收货地址自动计算邮费/超重费，生成补邮订单 | 补邮计算困难（#7） |
| **物流单号回写** | 支持批量导入物流单号或对接代发公司API，团员可在APP内实时查看物流状态 | 进度黑盒 |

#### 模块五：信用与风控

| 功能 | 描述 | 解决痛点 |
|---|---|---|
| **黑名单共享池** | 团长可将跑单用户加入黑名单，系统在其他团下单时自动提醒团长。支持黑名单理由和申诉机制 | 黑名单不共享（#8） |
| **团员信用分** | 根据历史跟团记录（完成率、按时付款率）自动计算信用分，高信用享优先权 | 逃单频发 |
| **团长信用展示** | 展示团长开团历史、发货率、好评率、实名认证标识 | 团长可信度无法判断 |

#### 模块六：进度与通知

| 功能 | 描述 | 解决痛点 |
|---|---|---|
| **团进度条** | 可视化展示当前团的阶段（设计中→打样中→制作中→到货→发货中），团长一键更新 | 团员进度黑盒 |
| **关键节点推送** | 打样完成、到货、催付、发货等关键节点自动推送APP通知+小程序服务通知 | 通知触达弱（#11） |
| **管理员权限系统** | 团长可设置1-N个管理员，分配"审核订单/回复咨询/管理商品"等细粒度权限 | 客服负担重 |

### 3.3 V2 — 社区化升级（留住用户）

| 功能 | 描述 | 目标 |
|---|---|---|
| **收藏柜/展示墙** | 团员可展示自己的谷子收藏，支持鉴定/估值标签 | 提升APP留存，制造下载动力 |
| **兴趣圈子** | 按IP/作品创建圈子，团长在圈内发团，团员在圈内交流 | 形成社区，替代散落的QQ/微信群 |
| **团长主页** | 完整展示团长历史团、信用数据、粉丝数、在售团列表 | 建立团长个人品牌 |
| **闲置交易** | 支持团员之间的二手谷子交易，平台提供信用担保 | 拓展交易场景（Coser闲置等） |

### 3.4 V3 — 社区电商生态（远期愿景）

| 功能 | 描述 | 目标 |
|---|---|---|
| **画师入驻/约稿平台** | 画师展示作品集，团长可直接约稿并在平台内管理稿件进度 | 打通供应链上游 |
| **工厂/供应链对接** | 提供经认证的工厂资源库，团长可直接下单打样/大货 | 解决自制团长供应链痛点 |
| **IP圈层社区** | 类Weverse/Bubble的兴趣社区，偶像/创作者与粉丝直接互动 | 成为兴趣人群聚集地 |
| **直播/签售** | 支持团长/创作者在APP内直播、线上签售 | 多元变现 |
| **数据决策引擎** | AI驱动的开团建议（热度预测、定价建议、捆绑比例优化） | 帮助团长更科学决策 |

## 四、AI 能力融合点

| 场景 | AI应用 | 价值 |
|---|---|---|
| **开团模板生成** | 团长输入IP名称+品类，AI自动生成商品列表模板、推荐冷热分池和捆绑比例 | 降低开团门槛 |
| **智能排表** | AI根据历史数据+当前规则自动生成最优排表方案 | 消灭手工排表 |
| **智能客服** | AI回答团员常见问题（进度查询、规则解释、补邮计算） | 释放团长客服压力 |
| **智能对账** | AI自动匹配转账凭证与订单（OCR识别截图金额+备注） | 消灭人工审核 |
| **宣传图生成** | 团长上传商品图，AI自动生成适配小红书/QQ空间风格的宣传图（注意：绝不能用AI生成商品设计图本身，圈内极度敏感） | 降低宣传门槛 |
| **热度预测** | 基于历史开团数据预测各角色/品类热度，辅助冷热分池决策 | 减少开团失败率 |

> **重要提醒**：AI仅用于流程效率提升（排表、对账、客服、宣传），**绝对不能用于商品设计/绘画环节**。圈内对AI画图极度敏感，曾有团长因画师使用AI导致信用崩塌、半年无法开团的真实案例。

## 五、商业化路径

| 阶段 | 策略 | 依据 |
|---|---|---|
| V1 早期 | **完全免费**，不收任何费用 | 会议明确"可以不考虑变现，像闲鱼一样7年不收钱"。先圈用户 |
| V1 成熟期 | **基础免费 + VIP订阅（9.9-29.9元/月）** | VIP提供高级导出、提额、数据看板等功能。访谈显示盈利型团长愿付29.9/月 |
| V2 | **免费 + 广告（轻量级，类番茄小说模式）** | 非盈利团长对订阅抵触，但容忍轻广告 |
| V3 | **交易佣金（极低费率）+ 供应链服务费** | 参考闲鱼模式，用户生态成熟后逐步引入 |

**明确不做的**：
- 不做转单服务费（小额场景普遍不接受）
- 不做按团员人数收费（团长C明确拒绝）
- 不做偏向买家的纠纷机制（团长群体强烈反感淘宝/微店的买家保护逻辑）

## 六、竞品差异化定位

| 竞品 | 定位 | 缺陷 | 我们的机会 |
|---|---|---|---|
| **拼团呀** | 通用拼团小程序 | 收款割裂（C2C扫码）、数据不透明、不支持冷热捆绑、日限额 | 原生集中收款 + 冷热捆绑引擎 + 实收看板 |
| **快团团** | 社区团购工具 | 偏生鲜/日用品，不理解兴趣圈层规则 | 深度理解谷圈/二次元/追星场景 |
| **微店** | 轻电商平台 | 偏向买家、退款随意、团长无安全感 | 平台中立或偏向团长 |
| **闲鱼** | 二手交易平台 | 无开团能力、无团长工具 | 从工具切入，沉淀社区 |
| **群拼股助手** | QQ群内小程序 | 功能简陋，只能导出表格 | 全流程闭环 |

## 七、V1 MVP 优先级排序

按"痛点严重度 × 影响用户数 × 实现难度"综合排序：

| 优先级 | 功能 | 理由 |
|---|---|---|
| **P0-必做** | 平台集中收款 + 分段收费 | 收款割裂是所有团长最痛的问题，也是留住团长的基础 |
| **P0-必做** | 自动排表 + 批量建品 | 消灭手工Excel，直接解放团长最耗时的环节 |
| **P0-必做** | 智能对账看板（实收/待收/应收） | 数据不透明是拼团呀用户最大抱怨 |
| **P0-必做** | 订单状态机 + 自动催付 | 从下单到发货的全流程管理是工具的骨架 |
| **P1-应做** | 冷热捆绑规则引擎 | 代购型团长的核心差异化需求，但实现复杂度较高 |
| **P1-应做** | 黑名单共享池 | 所有团长强烈需求，且是"社区"属性的起点 |
| **P1-应做** | 团进度条 + 关键节点推送 | 解决团员侧最大痛点，且实现成本低 |
| **P1-应做** | 分批/合并发货 | 代购型团长的刚需 |
| **P2-可做** | 智能补邮计算 | 频率中等，但解决了一个长链路痛点 |
| **P2-可做** | 转单功能 | 代购团需要，自制团不太需要 |
| **P2-可做** | 管理员权限系统 | 大团刚需，小团不急 |
| **P2-可做** | 动态调价/阶梯定价 | 团长觉得"不麻烦但要有" |

---

## 八、核心洞察总结

1. **团长是"用爱发电的小微创业者"**：他们急需一套兼具"电商后台专业性"与"社群运营灵活性"的工具。任何能将手工Excel+微信催款+人工审核自动化的功能，都是强烈刚需。

2. **效率是第一生产力**：团长一年只能开3-4团的根本原因是效率太低。如果工具能将单团周期从3个月压缩到1个月，团长收入可翻倍，这是最强的拉新钩子。

3. **收款闭环是护城河**：当前所有竞品的收款都是C2C扫码模式。谁能率先做到"平台内集中收款+自动对账+零手续费提现"，谁就能锁住团长。

4. **信用体系是社区基石**：黑名单共享+团长信用+团员信用三位一体，是从"工具"进化到"社区"的关键转折点。

5. **AI是效率放大器，不是内容生产者**：AI在排表、对账、客服、宣传等流程环节可以极大提效，但绝不能触碰"画师设计"这条红线。

6. **先做团长工具，再做社区电商**：不要一上来就做社区，先用极致的工具体验锁住团长，团长会自然带来团员，团员积累到一定规模后社区自然涌现。
