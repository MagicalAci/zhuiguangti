## 〇、基础框架

1. **桌面手机壳 + 移动端自适应**
  电脑浏览器打开自动套上手机外框（接近真机预览），手机端打开则全屏显示。
2. **路由打通**
  保留原 App 登录 / 注册页，登录后进入主业务流程（H5 原型主体）。
3. **顶部"团长视角 / 团员视角"切换器避开手机灵动岛**
  防止视角切换按钮被刘海遮挡。

---

## 一、发起拼团流程（团长开团）

1. **删除冗余汇总信息**
  移除「预计实付总和 / 拿货价 / 预计毛利」模块（团长视角无需展示自己的成本利润）。
2. **添加商品支持二选一**
  弹出「手动上传 / AI 识图批量上传」两种方式：
  - **手动上传**：原流程不变。
  - **AI 识图批量上传**：上传一张包含全部商品的图片，AI 模拟识别后批量导入；识别不到的字段（名称 / 价格）留空待补。
3. **「补尾款时间」改成日期选择器**
  并新增「到日期自动提醒团员」开关，自动到期触发推送。
4. **编辑拼团时去掉商品相关表单**
  商品维度调整由独立的「修改商品」模块承担，避免重复入口。

---

## 二、发布后流程

1. **新增「转发至群」+「一键保存二维码」按钮**
  团长发布完拼团即可分享 / 留存。
2. **「转发至群」需先实名认证**
  未认证团长会被拦截，引导进入实名认证流程；通过后才能转发。

---

## 三、团长视角 · 拼团详情页

1. **底部按钮重组为三入口**：编辑 / 拼团情况 / 我的订单，定位更清晰。
2. **「编辑」弹出二级选择**：
  - **修改拼团**：可改基础信息、付款方式、邮费等（除商品外）。
    - **修改商品**：进入商品编辑页，可改件数 / 价格 / 名称 / 图片。
3. **新增「催款管理面板」**（顶部高亮区域）：
  - **一键通知补尾款**（含截止时间、金额、通知渠道选择）
    - **一键通知补邮费**

## 四、团长视角 · 拼团情况（原"拼车情况"重命名）

1. **更名为「拼团情况」**。
2. **新增「撤排」功能**：
  - 入口：底部图例行末「🚫 撤排」按钮（默认温和灰，启用变橙黄）。

## 六、团长视角 · 进行中订单管理（**全新页面**）

> 入口：团长「我的」→ 我的订单 → 进行中

1. **顶部 4 个分类总览（一行 4 列紧凑版）**：
  凑车中 / 待补邮 / 待补尾款 / 待审核。
    点击 tile 即按该状态筛选，**支持多选**（可同时勾选多个状态，列表自动汇总展示）。
2. **筛选按钮（多选 ActionSheet）**：
  - 含 5 个状态（含"待支付"等 tile 未展示的状态）。
    - 复选框风格 + 实时计数。
    - 底部「🗑 清空」/「确定 (N)」按钮。
3. **批量选择模式**：
  - 勾选订单后底部弹出操作栏。
    - **🗑 批量删除**（含二次确认弹窗）。
    - **🔔 一键提醒**（仅「待补邮 / 待补尾款」可点，自动跳出对应通知弹窗，按多数状态默认 Tab）。
    - 选中订单含其他状态时按钮自动 disable + 文案提示。
4. **订单卡片细长两行布局**：
  - **第一行**：用户头像 + 姓名 ··· 拼团名 + 状态徽章
    - **第二行**：商品 ··· 应付金额

## 九、可演示的核心场景（评审 / 演示用）

1. **团长完整开团流程**：基础信息 → AI 识图加商品 → 配置定金 / 补尾款日期 → 发布 → 实名认证 → 转发到群
2. **团长 AI 审核**：进入待审核 → 一键 AI 审核 → 应用建议
3. **团长一键催款**：详情页催款面板 → 选时间 / 金额 / 通知渠道 → 提交
4. **团长批量管理订单**：我的 → 进行中 → 多选筛选 → 批量选择 → 一键提醒 / 删除
5. **团长撤排**：拼团情况 → 撤排 → 点头像 → 确认撤走
6. **团员订单全周期**：我的 → 不同 Tab 查看订单 → 待付款的提示直接进入付款流程

---

## 十、技术要点

- 所有改动以 H5 单文件 `public/h5demo.html` 完成，便于快速迭代和评审。
- 登录页保留为 React Native 原生页面（`app/login.tsx`），登录成功后跳转到 `/h5demo` 路由，通过 iframe 嵌入主流程。
- 所有交互均使用原生 JavaScript + CSS 实现，无外部依赖；可单独打开 HTML 文件演示，也可部署到任意静态托管。
